Phase 2.1: Toast 基础设施 — 设计方案

基于 daisyUI 5 Toast + Alert 组件，封装 Vue 3 Composable

三个文件

src/composables/useToast.js ← Composable（状态 + 方法）

src/components/ToastContainer.vue ← 渲染层（daisyUI 样式）

src/App.vue ← 修改：引用 ToastContainer

调用方式

toast.success('上传成功')
toast.error('网络异常')
toast.warning('文件过大')
toast.info('提示信息')

视觉效果（顶部居中）

Toast 堆叠示意 — daisyUI 原生样式
❌ 上传失败，文件格式不支持
✅ 文档已上传，处理中...
ℹ️ 新消息提醒已开启

行为规则

自动消失success / info / warning ：3 秒后淡出
手动关闭error ：需点击 X 关闭（防止错过关键错误）
堆叠多条 toast 从上到下排列，最多 5 条
动画进入：滑入 + 淡入 / 退出：淡出

设计决策

Composable 非 Pinia — toast 是通知，不是数据

daisyUI 原生样式 — 不重复造轮子

error 手动关闭 — 用户需要看到错误信息

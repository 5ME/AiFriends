## 服务器部署

### 前置操作

#### 授权

安装 acl：`sudo apt install acl`

授权：

```bash
sudo setfacl -m u:www-data:x /home/gqyin
sudo setfacl -R -m u:www-data:rX /home/gqyin/ai-friends
# 验证 ACL 是否生效：getfacl /home/gqyin 会看到 user:www-data:--x
getfacl /home/gqyin
```

#### 生成证书

云厂商的证书一般都需要域名，而域名备案又比较麻烦，暂时先这样处理

```bash
sudo mkdir -p /etc/nginx/ssl
sudo openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
  -keyout /etc/nginx/ssl/aifriends-selfsigned.key \
  -out /etc/nginx/ssl/aifriends-selfsigned.crt
```

#### Nginx 配置

创建文件 `/etc/nginx/sites-available/aifriends`

```
server {
    listen 80;
    server_name _;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    server_name _;

    ssl_certificate /etc/nginx/ssl/aifriends-selfsigned.crt;
    ssl_certificate_key /etc/nginx/ssl/aifriends-selfsigned.key;

    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;

    access_log /var/log/nginx/aifriends-access.log;
    error_log  /var/log/nginx/aifriends-error.log; 

    location /static/ {
        alias /home/gqyin/ai-friends/backend/static/;
        expires 30d;
    }

    location /static/frontend/vad/ {
        alias /home/gqyin/ai-friends/backend/static/frontend/vad/;
        expires off;
        add_header Cache-Control "public, max-age=2592000, immutable";
    }

    location /media/ {
        alias /home/gqyin/ai-friends/backend/media/;
        expires 30d;
    }

    location / {
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_pass http://unix:/home/gqyin/ai-friends/backend/gunicorn.sock;
    }
}
```

连接 `sudo ln -s /etc/nginx/sites-available/aifriends /etc/nginx/sites-enabled/`



#### Docker 服务（PG + Redis）

```bash
cd ~/ai-friends

# 启动 PostgreSQL + Redis
docker compose up -d

# 查看状态
docker compose ps

# 查看日志
docker compose logs -f
```

**Redis 说明：**
- 版本 `7-alpine`，仅约 15MB
- 数据持久化至 `/home/ygq/redis-data`（`--save 60 1`：每 60 秒至少 1 次写入时存盘）
- 连接：`redis://localhost:6379/0`



### 部署操作

1. 修改 frontend/src/js/config/config.js

   - 将 `platform` 的值修改为 `cloud`

2. 前端打包

   - `npm run build`

3. 传送文件到云服务器

   - `scp -r backend gqyin@115.190.245.146:ai-friends/`

4. 修改 backend/backend/settings.py

   - 将 `DEBUG` 的值修改为 `False`

5. 收集静态文件

   - `python manage.py collectstatic`

6. 启动 gunicorn

   - ```bash
     # 在 ~/ai-friends/backend/ 目录下执行
     gunicorn --workers 3 \
     --graceful-timeout 3 \
     --bind unix:/home/gqyin/ai-friends/backend/gunicorn.sock \
     backend.wsgi:application
     ```

7. 启动 Celery Worker（异步记忆摘要）

   - ```bash
     # 在 ~/ai-friends/backend/ 目录下执行
     celery -A backend worker -l info -c 1 &
     ```
     
     生产环境使用 systemd 管理进程，以下为示例 `celery-worker.service`：
     
     ```
     [Unit]
     Description=Celery Worker for AI Friends
     After=network.target
     
     [Service]
     Type=simple
     User=gqyin
     Group=gqyin
     WorkingDirectory=/home/gqyin/ai-friends/backend
     ExecStart=/home/gqyin/miniconda3/envs/py312/bin/celery -A backend worker -l info -c 1
     Restart=on-failure
     RestartSec=5s
     
     [Install]
     WantedBy=multi-user.target
     ```
